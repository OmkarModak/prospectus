## 🚀 How to Deploy to GitHub Pages (Only 2 Minutes)

### Step 1: Create a GitHub Repository
1. Log in to your GitHub account: **[github.com/new](https://github.com/new)**
2. Set **Repository name** to: `prospectus` (or `date-pitch` or `for-shraddha`)
3. Choose **Public**.
4. Leave all checkboxes (README, .gitignore, license) **UNCHECKED**.
5. Click **Create repository**.

### Step 2: Push to GitHub
In PowerShell, run these two commands from `c:\Users\modak\Desktop\date-pitch`:

```powershell
git remote add origin https://github.com/OmkarModak/prospectus.git
git push -u origin main
```
*(Replace `prospectus` with whatever repo name you chose)*

### Step 3: Turn on GitHub Pages
1. On your GitHub repo page, click **Settings** (top navigation tab).
2. Click **Pages** in the left sidebar menu.
3. Under **Build and deployment > Branch**, choose **`main`** and folder **`/ (root)`**, then click **Save**.
4. In about 60 seconds, your site will be live at:
   ```
   https://OmkarModak.github.io/prospectus/
   ```
