# 📈 Project Bullish: The Mumbai ⇄ Goa Date Proposal

A bespoke, high-yield, interactive date proposal website crafted for someone special in finance and world travel.

## ✨ Highlights & Concept
- **The Financial Narrative:** Framed as an unsolicited, highly accretive M&A ("Meet & Americano ☕") investment memorandum.
- **The Dalal Street ⇄ Goa Dynamic:** Plays on the contrast between Mumbai’s fast-paced market intensity and Goa’s sunset susegad tranquility.
- **The World Traveler Hook:** Acknowledges her extensive international travels while positioning you as the dedicated listener for her travel stories and local guide for hidden coastal cafes.
- **Senior Partner Advantage:** A playful, respectful nod to her being 1 year older ("Senior Partner with +1 Year Market Wisdom and full veto authority").
- **Interactive First-Class Boarding Pass:** Dynamically updates routes (e.g. `BOM ✈ GOX`), dates, and stamps an animated visa seal in real-time.
- **Playful Order Terminal:** 
  - **Execute Order (I'm In) 📈:** Fires celebratory confetti, plays audio chimes, and opens a direct one-tap WhatsApp confirmation pre-filled with her chosen date & venue!
  - **Short The Position 📉:** Playfully dodges clicks/hovers with humorous SEBI / circuit breaker regulatory warnings.

## 🚀 How to Deploy to GitHub Pages (2 Minutes, Free)

### Step 1: Create a GitHub Repository
1. Log in to [GitHub.com](https://github.com) and click **New Repository** (green button).
2. Name it something subtle and cute, for example: `prospectus` or `market-brief` or `date-pitch`.
3. Set it to **Public**.
4. Leave "Add a README" unchecked, then click **Create repository**.

### Step 2: Push These Files
Open your PowerShell / Terminal in `c:\Users\modak\Desktop\date-pitch` and run:

```powershell
git init
git add .
git commit -m "Initial launch of $BOM_GOA IPO prospectus"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/REPO_NAME.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** (tab at top) → **Pages** (in left sidebar).
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. In about 60 seconds, GitHub will give you your live URL:
   `https://YOUR_GITHUB_USERNAME.github.io/REPO_NAME/`

## 🎨 How to Personalize

### Method A: Via the Web Page
Once you open the page, click the **⚙️ Customize** button in the top right. You can enter:
- Her Name (e.g. *Pooja*, *Rhea*, *Aditi*)
- Your Name
- Your WhatsApp number (with country code, e.g. `919876543210`)
Then click **🔗 Copy Shareable Link**. It automatically encodes everything into the URL!

### Method B: Via URL Query Parameters
You can append details directly to your GitHub Pages URL:
```
https://YOUR_USERNAME.github.io/date-pitch/?name=Aditi&from=Rohan&phone=919876543210
```

### Method C: Directly in `config.js`
Edit [config.js](file:///c:/Users/modak/Desktop/date-pitch/config.js) before pushing to GitHub.
